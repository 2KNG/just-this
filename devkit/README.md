# 개발 도구 모음 (devkit)

자주 쓰는 개발 유틸을 한 곳에. **전부 브라우저에서 처리** → 토큰·키 같은 민감정보를 남의 사이트에 안 붙여넣어도 됨(프라이버시), 광고·추적 없음.

## 도구
- **JSON** 정리/압축/검증
- **Base64** 인코드/디코드 (UTF-8)
- **URL** 인코드/디코드
- **JWT** 디코드 (header/payload — 서명 검증은 안 함, 로컬 디코드)
- **해시** SHA-1/256/384/512 (Web Crypto)
- **타임스탬프** epoch ↔ 날짜
- **UUID** v4 생성

## 실행
허브에 묶여서 → `http://localhost:8000/devkit/`. 단독: `uvicorn app:app`
