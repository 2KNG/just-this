# 유튜브 추출 (ytdl)

유튜브(및 yt-dlp 지원 사이트)에서 영상/오디오를 받아오는 웹앱. 광고·악성 팝업 범벅 다운로더 사이트 대신 로컬에서.

## 기능
- **영상(MP4)** — 화질 선택 (최고/1080p/720p/…)
- **오디오(MP3)** — 음원만 추출 (192kbps)
- **구간 자르기** — 시작~끝(초)만 받기 (yt-dlp download-sections)
- **자막 포함** — 있으면 영상에 임베드
- **재생목록 → MP3** — 재생목록 링크 넣으면 곡 목록을 보여주고, 체크한 곡만 일괄 mp3 추출해서 zip 으로
  (1곡이면 mp3 그대로). 음질 320k(기본)/192k/128k, 파일명 순번(`01 - 제목.mp3`), 제목·아티스트·앨범아트 태그.
  백그라운드로 돌면서 진행률 표시, 중간 취소 가능. 한 곡이 막혀도 나머지는 계속. 최대 300곡.
  크롬을 `--enable-blink-features=CanvasDrawElement`(HTML-in-Canvas 오리진 트라이얼)로 띄우면 진행 패널에
  회전 디스크·현재 곡 카드 무대가 그려진다 — 장식일 뿐이라 없어도 똑같이 동작.

## 실행
보통 just-this 허브에 묶여서 한 번에 돈다 → `http://localhost:8000/ytdl/`.
단독: `pip install -r requirements.txt && uvicorn app:app`

## 메모
- **인터넷 연결 필요** — 서버(이 PC)가 직접 받아서 브라우저로 내려준다. 개인 보관용으로 사용.
- ffmpeg 는 시스템에 있으면 그걸, 없으면 pip `imageio-ffmpeg` 정적 빌드 자동 사용 (영상+오디오 병합, mp3 변환에 필요).
- 받은 파일은 임시폴더에 잠깐 뒀다가 30분 후 자동 정리. 재생목록 결과도 마찬가지 — "결과 받기"는 30분 안에.
- 재생목록은 서버 재시작하면 진행 중이던 작업이 사라진다 (메모리에만 들고 있음). 동시 작업은 2개까지.
