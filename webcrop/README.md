# PDF·문서 자르기·회전·변환 (webcrop)

PDF/스캔본을 회전·자르고 다른 포맷으로 바꾸고 싶을 때. 온라인 변환 사이트 결제·광고 없이 로컬에서.

## 기능
- **실시간 회전** — -180~180° 슬라이더 + 직접 수치 입력. 브라우저에서 바로바로 적용(Cropper.js).
- **자르기 + 테두리 스냅** — 마우스 드래그로 영역 지정. 스냅 켜면 내용(글자·도형) 경계에 딱 맞춤. on/off.
- **용지 규격 실치수 맞춤** — A4 / A3 / A5 / Letter / Legal / Tabloid / 명함.
  용지 고르면 PDF가 **그 용지의 정확한 물리 치수**로 나옴 (A4 = 정확히 210×297mm).
- **자동 기울기 보정(deskew)** — 틀어진 스캔본 각도를 감지해 똑바로 (선택).
- **포맷 변환** — PDF / PNG / JPG 입력 → PDF / PNG / JPG 출력 (여러 장은 zip). 기본 무손실.

좌표 정확성: 회전+크롭은 브라우저에서 보이는 그대로(WYSIWYG)를 결과로 만들어 보낸다.

## 실행
보통 **just-this 허브에 묶여서** 한 번에 돌아간다 (루트 README의 "한 번에 설치·실행"). 허브를 띄우면 `http://localhost:8000/webcrop/` 로 접속.

단독으로 띄우려면:
```bash
pip install -r requirements.txt
uvicorn app:app            # http://localhost:8000
```

## 사용 흐름
1. 파일 선택 → (필요하면 deskew 체크) → **불러오기**
2. **회전 슬라이더**(-180~180, 직접 입력 가능)로 실시간 회전, 페이지 위에서 **드래그로 crop**.
   **테두리 스냅** 켜면 내용 경계에 자동으로 딱 맞춤.
3. 용지 규격(실치수)·출력 형식·화질 고르고 **변환·다운로드**

## 주의
- 미리보기/작업 해상도는 200DPI. 회전+크롭 결과를 브라우저가 그대로 만들어 보내므로 보이는 게 결과.
- 용지 미선택 시 출력 물리 치수는 원본 스캔(200DPI 기준)을 따른다. 정확한 규격이 필요하면 용지를 고를 것.
- 세션(미리보기)은 임시폴더 저장, 30분 후 자동 정리. 업로드 50MB 제한.
- 단일 프로세스로 실행 (run.py 가 그렇게 띄움).
