# 문서 보정·변환 (webcrop)

스캔본이 틀어졌거나, PDF를 잘라서 다른 포맷으로 바꾸고 싶을 때. 온라인 변환 사이트 결제·광고 없이 로컬에서.

## 기능
- **자동 기울기 보정(deskew)** — 틀어진 스캔본 각도를 감지해 똑바로
- **회전** — 90/180/270도 + 미세 각도 슬라이더
- **자르기** — 마우스 드래그로 영역 지정 (Cropper.js)
- **용지 규격 맞춤** — A4 / A3 / A5 / Letter / Legal / Tabloid / 명함
- **포맷 변환** — PDF / PNG / JPG 입력 → PDF / PNG / JPG 출력 (여러 장은 zip)

## 실행
```bash
pip install -r requirements.txt
uvicorn app:app --reload          # http://localhost:8000
```

호스팅:
```bash
uvicorn app:app --host 0.0.0.0 --port 8000
```

## 사용 흐름
1. 파일 선택 → 보정 옵션 설정 → **불러오기·보정 적용** (서버가 펴서 미리보기)
2. 보정된 이미지 위에서 **드래그로 crop 박스**. 용지 고르면 비율 고정
3. **변환·다운로드**

## 주의
- 세션을 메모리/로컬 temp에 저장하므로 **uvicorn 멀티 워커로 띄우면 깨짐**. 호스팅 시 워커 1개로 두거나 세션 저장소를 공유 스토리지(Redis 등)로 교체.
- 업로드 50MB 제한, 세션 30분 후 자동 정리.
- `deskew`는 텍스트 위주 문서에서 잘 동작. 사진/도형 위주면 미세 각도를 수동으로.
