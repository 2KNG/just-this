# just-this 허브 (hub)

레포 안의 모든 도구를 한 페이지에서 보고 들어갈 수 있는 **셀프호스팅 대시보드**. 도구 창고의 현관.

각 도구 폴더의 `tool.json` 을 **매 요청마다 자동으로 읽어서** 카테고리·검색·태그로 보여준다. 루트 `README.md` 의 정적 메뉴와 같은 데이터를 쓰되, 이쪽은 살아있는 웹 버전. **새 도구를 추가하면 새로고침만 해도 자동으로 뜬다 — 허브 코드는 손댈 필요 없음.**

## 기능
- `*/tool.json` 자동 탐색 → 카테고리별 카드 대시보드
- 이름/설명/태그/slug 실시간 검색 (브라우저에서 즉시 필터)
- 각 도구의 실행 명령 **복사 버튼**, 웹 도구는 **열기 ↗** 링크, 코드 폴더 링크
- `GET /api/tools` — 도구 메타데이터 JSON (프로그램으로 긁어 쓸 때)
- `GET /healthz` — 헬스체크

## 실행
```bash
pip install -r requirements.txt
uvicorn app:app                      # http://localhost:8000
```

같은 네트워크의 다른 기기에서 접속하려면:
```bash
uvicorn app:app --host 0.0.0.0 --port 8000
```

## 동작 방식
- `app.py` 가 부모 폴더(레포 루트)의 `index.py` 를 import 해서 `load_tools()` 로 도구를 탐색한다. 탐색 로직이 루트 메뉴 생성기와 **단일 소스**라, 메뉴와 대시보드가 어긋날 일이 없다.
- 별도 DB·설정 없음. 진실의 원천은 각 도구의 `tool.json` 하나뿐.

## 메모
- 허브는 도구를 **나열·안내**한다. 각 도구 서버는 해당 폴더에서 직접 띄운다(카드의 복사 버튼으로 명령 복사). 여러 도구를 동시에 띄우면 포트는 도구마다 다르게.
- (다음 후보) 허브에서 도구를 직접 프로세스로 띄워주는 런처 기능 — 포트 관리·프로세스 생명주기 때문에 v2로 분리.
