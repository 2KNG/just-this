# 이미지 변환·자르기 (imgconv)

이미지 형식변환·자르기·리사이즈를 **원본 화질 보존**으로. 온라인 변환 사이트(배치 제한·워터마크·광고) 없이 로컬에서.

## 기능
- **형식변환** — HEIC(아이폰)·PNG·JPG·WEBP·BMP·TIFF·GIF 입력 → PNG / JPG / WEBP 출력. "원본 유지"면 형식 그대로 두고 자르기·리사이즈만.
- **자르기** — 한 장일 때 마우스 드래그(Cropper.js). 자유 / 1:1 / 4:3 / 16:9 / A4 비율. 자르기는 **원본 풀해상도**에 적용 → 무손실.
- **리사이즈** — 긴 변 / 가로 / 세로 / 퍼센트 기준 (LANCZOS).
- **메타데이터 제거** — EXIF·GPS 위치정보 삭제 (기본 ON, 공유 전 프라이버시). 끄면 보존.
- **여러 장 일괄** — 형식·리사이즈·메타데이터를 한 번에 적용해 zip.

## 실행
이 도구는 보통 **just-this 허브에 묶여서** 한 번에 돌아간다 (루트 README의 "한 번에 설치·실행" 참고). 허브를 띄우면 `http://localhost:8000/imgconv/` 로 접속.

단독으로 띄우려면:
```bash
pip install -r requirements.txt
uvicorn app:app            # http://localhost:8000
```

## 메모
- HEIC 지원은 `pillow-heif`(libheif) 필요. 휠에 포함돼 보통 자동. `GET /healthz` 의 `heif` 값으로 확인.
- 투명 PNG → JPG 변환 시 알파가 사라지므로 배경색으로 합성(기본 흰색).
- 자르기 좌표는 브라우저가 보여주는(EXIF 방향 적용된) 화면 기준. 서버도 같은 방향으로 맞춰 자른다.
